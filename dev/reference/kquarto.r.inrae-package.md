# kquarto.r.inrae: 'Quarto' Book Templates Following the INRAE Graphic Charter

Ships an 'INRAE' template for the 'Quarto' books created with
'kquarto.r' (colours, fonts, logo, title page and bibliography) and
makes it the default template of the book creation helpers.
